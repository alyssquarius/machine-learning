# Reference photographs for the demo catalogue

Retrieved from Wikimedia Commons on 2026-10-28. All 50 photo-to-model mappings and each original file page, author, license, license URL, source credit and description are recorded in photo-sources.json. Author and license links are shown with each photo in the catalogue and detail view. Each photo retains its source license, including applicable CC BY-SA terms; the repository software license does not replace these licenses.

Photographs are resized thumbnails and may be cropped by the card layout. They illustrate the named model; colors, trims, markets, and model years may differ from the fictional listing. These are not photos of vehicles being sold. The older body-type SVGs are custom local illustrations retained for compatibility with already stored demo listings; the migration upgrades only these original defaults, preserving custom images and user listings.
